# Core Business Context

## Product & Brand
ModularAI is an AI analytics platform/service designed to turn fragmented, messy business data into clear, actionable dashboards, stock forecasts, recommendations, and automated reporting. 
The brand voice is playful yet professional, positioning the product as a "digital sanctuary" and a "spa day for your data," in stark contrast to complex, archaic enterprise tools (like SAP).

## Go-to-Market Strategy
The primary goals of the website are:
1. **Sales Validation & Credibility**: To act as a strong, credible front for B2B clients exploring the service.
2. **Free Data Audit**: The main call-to-action is an offer for a "Free Data Audit" where the team reviews the prospect's data (spreadsheets, ERP exports) to demonstrate value.
3. **Demo Exploration**: A frontend-only demo mode to let users experience a polished, simplified dashboard that highlights core features without requiring a complex backend setup.

## Current Stage
We currently operate **without a backend/VPS**. All website functionality must be strictly frontend-safe. Features like login flows or live dashboards run in "demo mode," using mock data, local state, or hardcoded interactive scenarios to show what the product *will* feel like without pretending to have a live backend.
