# Agent Context Documentation

Welcome to the ModularAI web portal documentation. This directory provides critical context for future AI agents working on this repository.

**Purpose**: To ensure any AI agent that is modifying this repository can quickly understand the business context, the architecture, and the codebase rules without needing to rediscover everything.

## How to Use This Folder

Future agents should read these files in the following order before making architectural or wide-reaching changes:

1. `core.md`: Understands what ModularAI is and what the website needs to achieve.
2. `repo-map.md`: Provides a map of where different parts of the project reside.
3. `agent-rules.md`: Contains strict implementation rules to preserve code quality, branding, and Vercel compatibility.
4. `apps-web-portal.md`: Explains how the current SPA is structured and how features like the demo work.
5. `architecture-decisions.md`: Details key technical decisions (e.g., why this is a frontend-only SPA).
6. `deprecated-and-removed.md`: Keeps track of outdated files, patterns, or copy that should be ignored or removed.
